## От небольших данных к большим
Ранее (в примере с компанией по доставке) обрабатывалось всего 10 записей о доставках. Теперь рассматривается ситуация со 100 000 записей — значительно больший объём данных.

Если попытаться загрузить все 100 000 записей одновременно, например так:
```python
# Try to load all delivery data into memory
all_distances = []
all_times = []
for i in range(100000):
    distance, time = load_delivery_record(i)
    all_distances.append(distance)
    all_times.append(time)
```
каждая единица данных должна поместиться в оперативную память (RAM) компьютера.
- При 100 000 записей это ещё может быть приемлемо.
- Но что если записей миллионы, или дополнительно добавляются данные о погоде, трафике, информации о водителях и тому подобное?

При таком масштабе компьютер может быстро исчерпать память и произойдёт сбой (`CRASH!`).

> **Вывод:** данные нужно загружать по частям (piece by piece). Практическое решение — работать с данными **батчами (batches)**: небольшими управляемыми фрагментами полного датасета (например, 100 000 записей делятся на Batch 1, Batch 2, Batch 3, Batch 4 и так далее).

## Три ключевых инструмента PyTorch для работы с данными
Батчинг — лишь часть картины. Перед тем как данные будут готовы к обучению, их нужно обработать, привести к нужному формату и подавать в модель так, чтобы она их понимала. За это отвечают три основных утилиты PyTorch:
- `transforms`
- `Dataset`
- `DataLoader`

Каждый инструмент отвечает за свою часть процесса, и они спроектированы так, чтобы хорошо работать вместе.

### transforms
Пример применения:
```python
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((mean,), (std,))
])
```
`transforms` — это операции, которые выполняются над каждой точкой данных при её загрузке, подготавливая данные для модели. `Compose` означает «выполнить перечисленные операции по порядку».

Нейронные сети довольно «капризны»: они обучаются намного лучше, когда все входные значения представляют собой небольшие числа, в идеале центрированные вокруг нуля. Именно для этого нужны два самых распространённых transform'а:
- `transforms.ToTensor()` — преобразует данные в PyTorch `tensor` и масштабирует значения так, чтобы они попадали в диапазон от 0 до 1 (например, `[2, 4, 6, 8, 10]` → `tensor([.2, .4, .6, .8, 1])`, деление каждого значения на максимум).
- `transforms.Normalize()` — дополнительно корректирует эти значения, центрируя их вокруг нуля и масштабируя с использованием стандартного отклонения (standard deviation) (например, `tensor([.2, .4, .6, .8, 1])` → `tensor([-1.41, -0.70, 0, .70, 1.41])`).

Эти преобразования помогают модели обучаться значительно эффективнее; подробнее о них и о других техниках трансформации будет рассказано в следующем модуле.

### Dataset
Следующий шаг — обернуть данные в объект `Dataset`, который подгружает (fetches) каждый образец (sample) с диска только тогда, когда его запрашивают, а не загружает всё сразу целиком. Это один из «секретов» работы с по-настоящему большими датасетами.

`Dataset` отвечает за:
- где на диске хранятся данные;
- как загрузить конкретный образец;
- сколько всего образцов в датасете;
- как применить переданные `transforms` к каждому образцу при его загрузке.

Пример:
```python
# PyTorch has many pre-built datasets
dataset = SomeDataset('./data', train=True, download=True, transform=transform)
```
- `'./data'` — путь для хранения данных локально на компьютере.
- `train=True` — выбор между обучающим (training) и тестовым (test) набором данных; подробнее об этом будет рассказано при обсуждении evaluation (оценки модели).
- `download=True` — скачивает данные, если их ещё нет по указанному пути.

Получить один образец из датасета можно просто через индексацию:
```python
first_item = dataset[0]  # Just gets one
```

В Module 3 будет показано, как использовать класс `Dataset` для создания собственных (custom) датасетов. Пока же используются готовые (pre-built) датасеты, доступные в PyTorch.

### DataLoader
После того как `Dataset` определён, для подачи данных батчами используется `DataLoader`. Это часть пайплайна, которая делает возможным обучение на больших датасетах, запрашивая у датасета по одному батчу за раз.

Пример:
```python
dataset_loader = DataLoader(dataset, batch_size=32, shuffle=True)
```
- `batch_size` — сообщает загрузчику, сколько образцов отдавать за один раз (в примере — 32).
- `shuffle` — включает перемешивание данных, что помогает модели обучаться ещё эффективнее.

## Полный пайплайн данных PyTorch
```python
# 1. Define your transforms
transform = SomeTransform()  # ToTensor + Normalize

# 2. Create Datasets with transforms
train_dataset = YourDataset('./data', train=True, transform=transform)

# 3. Create DataLoaders
train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)

# 4. Training
for batch_idx, (data, labels) in enumerate(train_loader):
    # Data arrives in batches, already transformed
    # Your model processes this batch
    output = model(data)
```

Такой паттерн эффективно обрабатывает датасеты, которые иначе перегрузили бы память компьютера. Работаете ли вы с тысячами записей о доставках или с миллионами изображений — принцип остаётся тем же: **загружать только то, что нужно, тогда, когда это нужно**.

Но получение данных в модель — только начало. В следующем видео рассматривается остальная часть ML pipeline, а также то, как loss-функции и оптимизаторы обновляют модель.
