## Пайплайн данных

### Импорты и transforms
Сначала нужно импортировать `torchvision` — библиотеку компьютерного зрения PyTorch. Она поставляется со встроенными популярными датасетами вроде MNIST, а также с инструментами обработки изображений.

Знакомые `transforms` применяются к MNIST:
```python
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,))
])
```
- `ToTensor` конвертирует изображения в тензоры и масштабирует пиксели из диапазона 0–255 в диапазон 0–1.
- `Normalize` затем сдвигает и масштабирует эти значения так, чтобы они были центрированы вокруг 0.

Числа `0.1307` и `0.3081` — это среднее значение (mean) и стандартное отклонение (standard deviation) всего обучающего набора данных. Нормализация каждого изображения одними и теми же значениями делает данные более согласованными (consistent), и это помогает модели обучаться быстрее. Подробнее об этом будет рассказано в следующем модуле.

### Загрузка датасетов
```python
train_dataset = torchvision.datasets.MNIST(
    root='./data', train=True, download=True, transform=transform)
test_dataset = torchvision.datasets.MNIST(
    root='./data', train=False, download=True, transform=transform)
```
- `root='./data'` — просто указывает, куда сохранять файлы на компьютере.
- `train=True` — говорит, что нужны 60 000 обучающих изображений.
- `download=True` — означает, что если MNIST ещё не скачан, его нужно скачать.
- `transform` — применяет заранее определённые шаги предобработки к каждому изображению автоматически.

Тестовый датасет почти идентичен — просто используется `train=False`, чтобы получить 10 000 тестовых изображений вместо обучающих. При этом используются те же `transforms` и то же место хранения. `torchvision` сам обо всём этом позаботится — и о скачивании, и об организации данных.

### Data loaders
```python
train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)
test_loader = DataLoader(test_dataset, batch_size=1000, shuffle=False)
```
- Для обучения `batch_size` выставлен в 64 — то есть по 64 изображения в каждом батче. При `shuffle=True` в каждую эпоху (epoch) модель будет видеть изображения в другом случайном порядке.
- Для `test_loader` используется `batch_size=1000` — значительно бо́льшие батчи, потому что во время тестирования градиенты не вычисляются.

**Почему обучающие данные перемешиваются (shuffle), а тестовые — нет?** Датасеты часто организованы по классам. Если не перемешивать данные, модель может увидеть подряд 6 000 нулей, прежде чем увидит хотя бы одну единицу. Она может выучить непреднамеренные паттерны — например, «ранние батчи — это нули, поздние батчи — это девятки» — вместо того, чтобы на самом деле выучить, что делает ноль похожим на ноль. Перемешивание смешивает всё так, что в каждом батче есть разнообразие: модель учит настоящие признаки каждой цифры, а не их позицию в датасете. А для тестирования модель уже закончила обучение — проверяется лишь, может ли она правильно распознавать цифры, и порядок здесь не важен.

## Построение нейронной сети
Пришло время выйти за рамки `Sequential` и построить кастомную архитектуру (custom architecture). Создаётся класс, наследующийся от `nn.Module`. Это даёт доступ ко всей функциональности PyTorch для нейронных сетей. В его `__init__` определяются слои.

### Зачем нужен nn.Flatten()
Это новый элемент. Изображения MNIST приходят в виде тензоров определённой формы. Когда PyTorch загружает одно изображение MNIST, он выдаёт тензор размерности `[1, 28, 28]` — это каналы (channels), высота (height) и ширина (width). Единственный канал означает, что изображение в оттенках серого — это просто одно значение яркости от 0 до 255 для каждого пикселя. 28 на 28 пикселей — это размер, то есть два других измерения.

Но при обучении на батчах PyTorch добавляет ещё одно измерение. Так, при `batch_size=64` данные приходят как `[64, 1, 28, 28]`: 64 изображения, у каждого один канал, и каждое размером 28 на 28 пикселей.

**Проблема:** линейные слои (`Linear`) ожидают плоские векторы (flat vectors) — одну длинную строку чисел на изображение, а не двумерные сетки. Именно это и делает `Flatten`: он берёт каждое изображение 28×28 и преобразует его в 784 значения в одной строке. Почему 784? Потому что `28 × 28 = 784`. Так батч вместо размерности `[64, 1, 28, 28]` становится просто `[64, 784]`. Без `Flatten` при попадании данных изображения в линейный слой возникнет ошибка несовпадения форм (shape mismatch error).

### Определение слоёв
```python
class MNISTClassifier(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.layers = nn.Sequential(
            nn.Linear(784, 128),
            nn.ReLU(),
            nn.Linear(128, 10)
        )

    def forward(self, x):
        x = self.flatten(x)
        x = self.layers(x)
        return x
```
Слои складываются с помощью `Sequential`:
- `nn.Linear(784, 128)` — берёт те 784 значения пикселей и преобразует их в 128 скрытых признаков (hidden features).
- `nn.ReLU()` — функция активации: оставляет положительные значения и обнуляет отрицательные.
- `nn.Linear(128, 10)` — берёт 128 признаков и превращает их в 10 выходов: по одному на каждый класс цифры (0–9, всего 10 цифр).

В методе `forward` определяется поток данных: вход поступает, `flatten` его сплющивает, дальше он проходит через слои (`layers`), и результат возвращается.
