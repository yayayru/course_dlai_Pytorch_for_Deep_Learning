## Конспект по коду

### Назначение

Практическая лабораторная работа по тензорам `PyTorch`: создание тензоров из разных
источников, изменение формы, индексирование/срезы, математические и логические операции.
Многие типичные ошибки в проектах на `PyTorch` связаны именно с формой, типом или
размерностью тензоров — лабораторная закладывает базу для уверенной работы с данными и
отладки таких ошибок. Завершается четырьмя необязательными (optional) упражнениями на
применение изученного к практическим сценариям.

### Ключевые импорты и настройки

- `torch`, `numpy as np`, `pandas as pd`.
- Данные для одного из примеров создания тензоров читаются из `data.csv`
  (три строки: `distance_miles`, `delivery_time_minutes`), лежащего рядом с notebook.

### Основные шаги в порядке выполнения

#### 1. Создание тензоров (Tensor Creation)

**1.1 — из существующих структур данных:**

- `torch.tensor([1, 2, 3])` — из Python-списка; целые числа сохраняются как `int64`.
- `torch.from_numpy(numpy_array)` — из `NumPy`-массива.
- Из `pandas.DataFrame` прямого метода конвертации нет: сначала данные извлекаются как
  `NumPy`-массив через `.values`, затем оборачиваются в `torch.tensor()`. В примере
  `df = pd.read_csv('./data.csv')`, `all_values = df.values`,
  `tensor_from_df = torch.tensor(all_values)` — результат имеет тип `torch.float64`.

**1.2 — с предопределёнными значениями** (полезно, например, для инициализации весов и
смещений перед обучением):

- `torch.zeros(2, 3)` — тензор из нулей заданной формы.
- `torch.ones(2, 3)` — тензор из единиц заданной формы.
- `torch.rand(2, 3)` — тензор со случайными числами, равномерно распределёнными от 0 до 1.

**1.3 — из последовательности:**

- `torch.arange(0, 10, step=1)` — 1D-тензор с диапазоном чисел от начального значения до
  значения на единицу меньше конечного, с заданным шагом.

#### 2. Изменение формы и манипуляции (Reshaping & Manipulating)

Частый источник ошибок в проектах на `PyTorch` — несовпадение формы входных данных с
формой, которую ожидает модель (например, модель обычно рассчитана на батч данных, и
даже для одного предсказания вход нужно оформить как батч размера 1).

**2.1 — проверка размерностей:** атрибут `torch.Tensor.shape` возвращает объект
`torch.Size`, описывающий размер тензора по каждому измерению — это основной
инструмент для отладки формы.

**2.2 — изменение размерностей:**

- `unsqueeze(dim)` — добавляет новое измерение по указанному индексу (форма `[2, 3]` →
  `[1, 2, 3]` при `unsqueeze(0)`).
- `squeeze()` — убирает измерения размера 1 (реверс `unsqueeze`).

**2.3 — реструктурирование:**

- `reshape(rows, cols)` — меняет форму тензора на заданную (например, `[2, 3]` →
  `reshape(3, 2)` → `[3, 2]`, с сохранением порядка элементов).
- `transpose(dim0, dim1)` — меняет местами указанные измерения тензора.

**2.4 — объединение тензоров:**

- `torch.cat((tensor_a, tensor_b), dim=1)` — объединяет последовательность тензоров вдоль
  существующего измерения (все размерности, кроме размерности объединения, должны
  совпадать).

#### 3. Индексирование и срезы (Indexing & Slicing)

**3.1 — доступ к элементам** (работает похоже на обычные Python-списки):

- обычное индексирование: `x[1, 2]` (один элемент), `x[1]` (целая строка), `x[-1]`
  (последняя строка);
- срезы (`slicing`): `x[0:2]` (первые две строки; конечный индекс не включается),
  `x[:, 2]` (весь третий столбец), `x[:, ::2]` (через один столбец), `x[:, -1]`
  (последний столбец);
- комбинирование индексирования и срезов: `x[0:2, 2:]`;
- `.item()` — извлекает значение одноэлементного тензора как обычное Python-число.

**3.2 — продвинутое индексирование:**

- **Boolean masking**: булев тензор как маска для выбора элементов по условию, например
  `mask = x > 6`, затем `x[mask]`.
- **Fancy indexing**: тензор индексов для выбора конкретных, не обязательно смежных
  элементов, например `x[row_indices[:, None], col_indices]`.

#### 4. Математические и логические операции (Mathematical & Logical Operations)

**4.1 — арифметика:**

- поэлементные операции (`+`, `*`) — применяются к каждому элементу независимо;
- скалярное/матричное произведение — `torch.matmul(a, b)` (для векторов — dot product);
- **broadcasting** — автоматическое расширение тензора меньшей формы до формы большего
  тензора при арифметических операциях, даже если формы не совпадают полностью, но
  совместимы.

**4.2 — логика и сравнения:**

- операторы сравнения (`>`, `<=`, `==`) — поэлементно, результат — булев тензор;
- логические операторы `&` (AND) и `|` (OR) — поэлементно над булевыми тензорами.

**4.3 — статистика:**

- `tensor.mean()` — среднее значение всех элементов;
- `tensor.std()` — стандартное отклонение всех элементов.

**4.4 — типы данных:**

- **Type casting**: конвертация тензора из одного `dtype` в другой, например `.int()`
  (из `float32` в `int32`). Подчёркивается, что нейронные сети обычно считают в
  `float32`, а данные неверного типа могут привести к ошибкам выполнения или неожиданному
  поведению при обучении.

#### 5. Необязательные упражнения (Optional Exercises)

Каждое упражнение даёт условие и код с заполненным решением (скрыт под `<details>` в
markdown, но присутствует и выполнен в code-ячейке; в notebook он уже раскрыт и
запущен — отдельного нерешённого варианта нет):

1. **Analyzing Monthly Sales Data.** Тензор `sales_data` (3 продукта × 4 месяца).
   Вычисляется суммарная продажа Product B (`sales_data[1].sum()`), булева маска месяцев
   с продажами Product C > 130 (`sales_data[2] > 130`), и срез за Feb/Mar для всех
   продуктов (`sales_data[:, 1:3]`).
2. **Image Batch Transformation.** Батч из 4 изображений `[batch, height, width]` =
   `torch.rand(4, 3, 2)`. Добавляется размерность канала (`unsqueeze(1)` →
   `[batch, channels, height, width]`), затем двумя последовательными `transpose()`
   канал переносится в конец формы (`[batch, height, width, channels]`).
3. **Combining and Weighting Sensor Data.** Два 1D-тензора (`temperature`, `humidity`)
   объединяются через `torch.cat` (после `unsqueeze(0)` каждого) в тензор `2×5`;
   создаётся тензор весов `torch.tensor([0.6, 0.4])`, применяется к данным через
   broadcasting (`weights.unsqueeze(1)`), затем вычисляется взвешенное среднее по
   `dim=0` с делением на сумму весов.
4. **Feature Engineering for Taxi Fares.** Тензор `trip_data` со столбцами
   `[distance, hour_of_day]`. С помощью срезов, сравнений (`>`, `>=`, `<`) и логических
   операторов (`&`, `|`) строится булева маска «длинная поездка в час пик», которая
   приводится к `float` и `unsqueeze(1)`, а затем присоединяется к исходным данным через
   `torch.cat(..., dim=1)` как новый признак.
