## Проблема: линейная модель перестаёт работать

В предыдущей лабораторной работе служба доставки расширилась с обслуживания только на
велосипедах до общегородских операций, используя автомобили для более дальних маршрутов.
Оказалось: с ростом расстояния время доставки перестало следовать прямой линии.

Причина — в предположении линейной модели: она считает, что каждая миля требует
одинакового количества времени, но в реальности всё сложнее:

- первые несколько миль за пределами зоны велосипеда попадают в плотный городской
  трафик;
- дальше автомобили выезжают на шоссе и движутся быстрее.

Зависимость искривляется (curves).

## Почему просто добавить нейроны не решает проблему

Идея «добавить больше нейронов» кажется логичной: если один нейрон учит одну
зависимость, возможно, несколько нейронов смогут уловить больше сложности.

- При одном нейроне он сразу производит финальное предсказание — то есть является
  выходным слоем.
- При добавлении второго нейрона появляется два выхода из одного входа, но нужен один
  финальный результат — поэтому добавляется ещё один нейрон, который объединяет эти два
  выхода в одно финальное значение.
- Эти два «промежуточных» нейрона теперь образуют **скрытый слой** (`hidden layer`): они
  независимо вычисляют взвешенную сумму от входа (обозначены как Z1 и Z2), а новый
  выходной нейрон принимает оба этих значения и объединяет их в единое предсказание.

**Проблема:** это всё равно остаётся линейным уравнением, сколько бы нейронов так ни
складывать. Если все операции над одним входом линейны (просто умножение на веса и
сложение смещений), результатом всегда будет прямая линия.

**Вывод.** Чтобы выучивать кривые, а не только прямые линии, модели нужно нечто большее,
чем линейное преобразование — нужны **нелинейные функции активации**
(`nonlinear activation functions`). Эти функции добавляют ровно столько сложности,
сколько нужно, чтобы модель могла выучивать более интересные закономерности. В `PyTorch`
их обычно применяют поэлементно (`element-wise`) к каждому нейрону слоя, по одному.

Механика: нейрон сначала вычисляет линейное преобразование входа, но вместо того, чтобы
сразу выдать это «сырое» число, оно пропускается через функцию активации. Именно это
небольшое изменение — добавление нелинейного преобразования — позволяет модели выучивать
намного более богатые закономерности.

## ReLU

**Определение.** `ReLU` (`Rectified Linear Unit`) — простая и при этом на удивление
мощная функция активации:

- если вход отрицательный, выход — ноль;
- если вход положительный, значение передаётся без изменений.

В `PyTorch` добавление `ReLU` к модели с одним нейроном занимает всего одну строку кода.
Через `Sequential` (тот же контейнер-«сборочная линия», пропускающий данные через слои по
порядку) данные проходят сначала через линейный слой, а затем через `ReLU`, который
трансформирует выход.

### Как ReLU помогает моделировать кривые

Нейрон вычисляет `W × distance + B`.

- Без `ReLU` это даёт прямую линию.
- С `ReLU`: когда `W × distance + B` отрицательно, выход равен нулю (плоская линия);
  когда положительно — выход следует линии как обычно.

Получается **изгиб** (bend) — точка, где поведение меняется.

**Где именно происходит изгиб.** Изгиб возникает там, где `W × X + B = 0`, то есть при
`X = −B / W` — в этой точке функция перестаёт выдавать ноль и начинает реагировать на
вход.

Городские данные о времени доставки на автомобилях изгибаются не один раз — кривая
плавно меняется по мере изменения дорожных условий на разных расстояниях. Если один
нейрон даёт один изгиб, несколько нейронов могут дать несколько изгибов.

### Несколько нейронов — несколько изгибов

У каждого нейрона свои вес и смещение, поэтому каждый нейрон активируется на своём
расстоянии. Пример с тремя нейронами, получающими один и тот же вход (расстояние):

- нейрон 1 активируется примерно на 3 милях, где начинается трафик;
- нейрон 2 активируется примерно на 8 милях, при въезде на шоссе;
- нейрон 3 активируется примерно на 15 милях, на полной скорости шоссе.

Если сложить их выходы вместе, комбинированный результат приближает сложную кривую.

## Код модели с несколькими нейронами

В `PyTorch` такая модель по-прежнему занимает всего несколько строк кода. Разбор:

- в коде определяются только два линейных слоя — вход не считается отдельным слоем,
  поскольку это просто данные, а `ReLU` — это функция активации, которая трансформирует
  значения, а не отдельный слой (в этом подсчёте);
- первый линейный слой — это группа нейронов: параметр `1` означает один входной признак
  (расстояние), параметр `3` означает три нейрона, то есть слой выдаёт три значения;
- каждое из этих трёх значений проходит через `ReLU`;
- второй линейный слой принимает эти три трансформированных значения и объединяет их с
  помощью одного нейрона, производя одно финальное предсказание — время доставки.

Если нужна более гладкая кривая, достаточно увеличить число нейронов в первом слое: при
достаточном количестве нейронов, каждый из которых учится, где активироваться и насколько
сильно вносить вклад, можно приблизить любую гладкую кривую — включая городские паттерны
транспортировки со всей их сложностью.

## Другие функции активации

`ReLU` используется потому, что это «рабочая лошадка» современного deep learning: она
быстрая, эффективная и широко применяемая. Но это не единственная функция активации:

- **Sigmoid** сжимает выходы в диапазон от 0 до 1 — хорошо подходит для вероятностей.
- **Tanh** отображает значения в диапазон от −1 до +1, что полезно для многих задач.
- Есть и много других функций активации; для более глубокого погружения упоминаются
  документация pytorch.org и другие специализации deeplearning.ai.

Для большинства ситуаций, однако, достаточно `ReLU`.
