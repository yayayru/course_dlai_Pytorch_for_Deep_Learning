# Tensor Math and Broadcasting

## Источники

- `07_video_Tensor_Math_and_Broadcasting.trans.txt`

## Контекст

В предыдущем видео было показано, как создавать, изменять форму и отлаживать тензоры.
Здесь разбирается, как `PyTorch` реально выполняет вычисления с ними.

## Поэлементные вычисления

Отправная точка — вычисление из модели с одним нейроном: `weight × distance + bias`, но
теперь для случая, когда нужно обработать сразу несколько значений расстояния.

- Тензорная математика `PyTorch` работает **поэлементно** (`element-wise`) — каждый
  элемент обрабатывается независимо.
- Вычисление применяет один и тот же вес к каждому расстоянию, а затем прибавляет одно и
  то же смещение к каждому результату.
- Математика выглядит как обычный Python, но `PyTorch` выполняет эти операции
  эффективно, сразу над всеми элементами.
- Это работает как для скаляров (одиночных значений), так и для тензоров одинаковой
  формы.

## Задача: более сложные данные

Пример: три доставки, у каждой по три признака — расстояние, час, погода. Требуется
применить корректирующие коэффициенты: например, ×1.1 для расстояния, без изменений для
времени, ×5 «штраф» за плохую погоду.

- Можно создать тензор, повторив строку `1.1, 1.0, 5.0` под каждую из трёх доставок — это
  сработает, потому что формы тензоров совпадают, но такой подход избыточен
  (redundant).
- Возникает вопрос: нельзя ли указать эти корректирующие значения только один раз?
  Именно для этого существует **broadcasting**.

## Broadcasting

**Определение.** `Broadcasting` — это автоматическое расширение тензора меньшей формы до
формы большего тензора при выполнении операций между ними, без явного повторения значений
вручную.

Отправная точка знания: тензоры одинаковой формы работают поэлементно. Но уже было видно,
что скаляр может обновлять каждое значение в тензоре расстояний (например, добавление
одного и того же веса и смещения ко всем расстояниям сразу) — когда к тензору
прибавляется скаляр, `PyTorch` автоматически расширяет это единственное значение, чтобы
оно совпало с каждым элементом. Именно это автоматическое расширение и есть broadcasting
в действии.

### Пример: тензор формы [1, 1] и тензор формы [1, 3]

Вопрос: сработает ли тензор со значением 5 и формой `[1, 1]` вместе с тензором формы
`[1, 3]`?

- Первый тензор имеет форму `[1, 3]` — 1 строка, 3 значения.
- Второй имеет форму `[1, 1]` — 1 строка, 1 значение.
- Обычно `PyTorch` требует точного совпадения размерностей для операций; разные формы
  вызвали бы ошибку.
- Но здесь работает «магия» broadcasting: когда одно измерение равно 1, а другое —
  больше, `PyTorch` автоматически расширяет меньшее измерение, повторяя значения. Так
  тензор формы `[1, 1]` со значением 5 становится `[5, 5, 5]`, совпадая с формой `[1, 3]`,
  и после этого тензоры можно сложить.

### Более сложный пример: [1, 3] и [3, 1]

Что произойдёт при объединении тензора формы `[1, 3]` с тензором формы `[3, 1]`?

`PyTorch` рассматривает каждое измерение отдельно:

- первое измерение: 1 против 3 — единица расширяется до 3;
- второе измерение: 3 против 1 — единица расширяется до 3;
- в результате оба тензора становятся формы `[3, 3]`.

### Практическое применение

Вместо того чтобы трижды повторять строку `1.1, 1.0, 5.0` для корректирующих
коэффициентов доставки, достаточно один раз задать эти значения — без циклов и ручного
повторения; `PyTorch` обрабатывает всё это через broadcasting.

Такой паттерн встречается повсеместно в deep learning:

- корректировка нескольких признаков между батчами;
- объединение разных измерений данных;
- эффективное применение трансформаций.

Как только научишься замечать broadcasting, возможности для его применения будут видны
повсюду.
