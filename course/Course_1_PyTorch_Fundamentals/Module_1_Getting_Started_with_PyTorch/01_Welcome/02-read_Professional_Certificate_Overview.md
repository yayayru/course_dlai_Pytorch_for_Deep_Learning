# Explore the Courses in This Professional Certificate
Welcome to the **PyTorch for Deep Learning Professional Certificate!** This three-course program will take you from the fundamentals of building and training neural networks in PyTorch to advanced architectures and model deployment.

[View All Courses](https://learn.deeplearning.ai/specializations/pytorch-for-deep-learning-professional-certificate/overview)
---

## Course 1: PyTorch Fundamentals
Start here to learn the core concepts of PyTorch and build your first neural networks. You’ll explore tensors, datasets, and the model training workflow that form the foundation for everything you’ll do in the later courses.
---

## Course 2: PyTorch — Techniques and Ecosystem Tools
Build on your foundation from Course 1 by learning advanced PyTorch techniques and tools.

- **Hyperparameter Optimization:** Tune model performance using learning-rate schedulers, flexible architectures, and Optuna for automated search
- **Working with Images using TorchVision:** Load, transform, and augment image data, and apply transfer learning to pretrained models
- **Working with Text using Hugging Face:** Process text data, use pretrained tokenizers and embeddings, and fine-tune transformer models
- **Efficient Training Pipelines:** Identify bottlenecks and speed up training with PyTorch Profiler and PyTorch Lightning
[Go to Course 2 Now!](https://learn.deeplearning.ai/specializations/pytorch-for-deep-learning-professional-certificate/lesson/oppq8g/a-conversation-between-laurence-moroney-and-andrew-ng)

## Course 3: PyTorch — Advanced Architectures and Deployment
Advance your PyTorch skills by exploring modern architectures and preparing models for real-world use.

- **Designing Custom Architectures:** Go beyond Sequential models and harness PyTorch’s dynamic computation graphs to build flexible, custom architectures using native Python control flow
- **Specialized Vision Techniques:** Explore CNN interpretability with saliency and class-activation maps, and experiment with diffusion-based image generation
- **Specialized NLP Techniques:** Understand how transformer architectures work—attention, encoders, decoders, and how they handle different language tasks
- **Preparing Models for Deployment:** Track experiments with MLflow, export models with ONNX, and compress them with pruning and quantization for efficient deployment
