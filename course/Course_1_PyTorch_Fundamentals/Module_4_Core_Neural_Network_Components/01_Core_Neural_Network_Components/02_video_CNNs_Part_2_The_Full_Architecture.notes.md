## От отдельных фильтров к полной архитектуре

В предыдущем видео было показано, как работают свёрточные слои и как CNN учатся полезным фильтрам для извлечения признаков и паттернов из изображений. Теперь эти элементы собираются в полную архитектуру convolutional neural network.

Класс модели, как и раньше, наследуется от `nn.Module`. В методе `__init__()` определяется структура сети: она начинается с двух свёрточных слоёв и заканчивается полносвязным (fully connected) слоем для классификации изображений.

> **Fully connected** — это просто другое название линейного слоя (`nn.Linear`): каждый нейрон входа связан с каждым нейроном выхода.

## Пример архитектуры `SimpleCNN`

```python
class SimpleCNN(nn.Module):
    def __init__(self):
        super(SimpleCNN, self).__init__()
        # First convolutional layer
        self.conv1 = nn.Conv2d(in_channels=1, out_channels=32, kernel_size=3, padding=1)
        self.relu1 = nn.ReLU()
        self.pool1 = nn.MaxPool2d(kernel_size=2)

        # Second convolutional layer
        self.conv2 = nn.Conv2d(in_channels=32, out_channels=64, kernel_size=3, padding=1)
        self.relu2 = nn.ReLU()
        self.pool2 = nn.MaxPool2d(kernel_size=2)

        # Flatten layer (no parameters, just reshaping)
        self.flatten = nn.Flatten()

        # Fully connected layer
        self.fc = nn.Linear(64 * 7 * 7, 10)

    def forward(self, x):
        x = self.conv1(x)
        x = self.relu1(x)
        x = self.pool1(x)

        x = self.conv2(x)
        x = self.relu2(x)
        x = self.pool2(x)

        x = self.flatten(x)
        x = self.fc(x)
        return x

model = SimpleCNN()
print(model)
```

### Первый свёрточный слой

Начинается с изображения с одним каналом, то есть с изображения в оттенках серого — у каждого пикселя одно значение яркости. Модель учится 32 разным фильтрам. Каждый фильтр — это сетка чисел 3×3, то есть по 9 весов на фильтр. Эти фильтры скользят по изображению и реагируют на разные паттерны; используется padding = 1.

Хотя выход этого слоя можно представить как 32 новых изображения, на самом деле это просто массивы числовых значений, показывающие, насколько сильно каждый фильтр отреагировал на разные участки изображения. Такие выходы обычно называют **feature maps** (или **activation maps**) — они показывают, где в изображении встречается каждый признак.

### ReLU-активация

Далее идёт активация **ReLU**: как и ожидается, она обнуляет все отрицательные значения в получившейся feature map. Это помогает модели учить более сложные паттерны.

### `MaxPool2d`: зачем нужен pooling

После ReLU данные подаются в `MaxPool2D`.

**Pooling** — распространённая техника в CNN, которая используется для уменьшения размера feature maps. По сути, это способ "выбросить" часть пикселей после применения фильтра, сжимая данные при сохранении наиболее важных частей так, чтобы это не должно было существенно повлиять на результат.

Пример работы (kernel size = 2 для MaxPool):

- Слева — feature map, полученная на выходе фильтра.
- Поскольку размер pooling-ядра равен 2, выбирается область 2×2.
- Из неё сохраняется только наибольшее значение в группе (в примере из презентации — 192), остальное отбрасывается. Именно поэтому техника называется **MaxPooling**.
- Если повторить этот процесс для каждой группы 2×2 значений в feature map, получится итоговый выход меньшего размера, где для каждой области 2×2 сохранено только максимальное значение.

Логика в том, что фильтры уже извлекли важные признаки из исходного изображения. Применяя pooling, происходит сжатие каждого отфильтрованного изображения, сохраняя только самую значимую информацию. В результате через сеть проходит меньше данных, а следующий слой видит изображения, размер которых составляет лишь четверть от исходного.

Это важно, потому что после первого свёрточного слоя получается уже 32 разных feature maps, поступающих во второй слой. Для больших изображений это быстро превращается в большой объём данных. Pooling уменьшает этот объём информации, делая нейронную сеть значительно более эффективной без потери ценных деталей и более устойчивой к небольшим изменениям.

### Полносвязный слой и расчёт его входного размера

После того как свёрточные и pooling-слои выделили и сжали ключевые признаки изображения, наступает время классифицировать результат с помощью fully connected слоя. Этот слой объединяет все признаки в итоговое предсказание.

В примере линейный слой имеет `64 * 7 * 7` входов.

- Число **64** очевидно: второй свёрточный слой даёт 64 выхода благодаря своим 64 фильтрам.
- Почему **7 × 7**? Если исходные фотографии природы были приведены к размеру 28×28 пикселей, то:
  - каждый MaxPooling-слой работает, беря изображение блоками 2×2, поэтому изображение 28×28 делится пополам по каждой оси, и получается 14×14;
  - второй pooling-слой делает то же самое, уменьшая 14×14 вдвое до 7×7.
  - Таким образом, feature maps размером 7×7 подаются на финальный линейный слой.

Иными словами, каждый MaxPooling-слой уменьшает размер своего входа вдвое.

### Метод `forward`

Метод `forward` определяет поток данных и достаточно прямолинеен: данные пропускаются через каждый свёрточный слой, а затем, вспоминая, что линейный слой ожидает одну строку значений, тензор "выпрямляется" (flatten) в единый вектор перед подачей в финальный слой для получения предсказания.

Это и есть полный CNN-пайплайн: от исходных пикселей — к выученным признакам — к классификации.

## Итог

К этому моменту показано, как CNN обрабатывает изображение:

- начиная с выученных фильтров, которые формируют feature maps;
- затем pooling для уменьшения размера и повышения устойчивости;
- и наконец, классификация через полносвязные слои.

Теперь понятна базовая теория, а в следующем видео код разбирается шаг за шагом — как построить convolutional neural network с использованием PyTorch.
