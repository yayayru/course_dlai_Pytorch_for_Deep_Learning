## Постановка задачи: расширение приложения ботанического сада

Бабочкин дом по соседству попросил расширить приложение так, чтобы оно могло классифицировать не только цветы, но и насекомых и мелких животных. Для этого нужна модель, которая умеет:

- распознавать более сложные образы;
- обнаруживать края, текстуры и паттерны на изображениях.

Такая модель называется **convolutional neural network (CNN)**.

### Проблема линейных слоёв

Ранее классификаторы строились на `nn.Linear`-слоях, но у них есть ограничение: линейный слой рассматривает каждый пиксель как независимый. Когда модель смотрит на изображение цветка или бабочки, она видит тысячи отдельных чисел без понимания того, что соседние пиксели вместе образуют такие признаки, как крылья, усики или глазчатые пятна.

## Биологическое происхождение CNN

CNN — основа компьютерного зрения, и их идея вдохновлена биологией. В 1960-х годах нейробиологи (Hubel и Wiesel, 1962) обнаружили, что некоторые нейроны зрительной коры реагируют только при появлении определённых паттернов (например, полос определённой ориентации). CNN имитируют это поведение с помощью фильтров, которые выделяют признаки на изображении и учатся на них.

## Как работает свёртка (convolution)

Рассмотрим пример на основе одной из фотографий природы из датасета — снимок в оттенках серого.

- При приближении видны отдельные пиксели с числовыми значениями яркости (в оттенках серого).
- Берётся центральный пиксель со значением **61**, а окружающие его пиксели образуют сетку **3×3** — его соседей.
- Задаётся **фильтр (filter)** — отдельная сетка чисел **3×3**, которая "скользит" по изображению.
- В каждой позиции значения фильтра умножаются на значения пикселей под ними, а результаты складываются — это меняет значение центрального пикселя.

Процесс скольжения фильтра по изображению и вычисления нового значения для каждого пикселя на основе его соседей называется **convolution (свёртка)**.

### Числовой пример (уточнён по презентации)

Пиксели вокруг центрального (значение 61):

```
191  126   78
 98   61   76
 94   91   92
```

Фильтр:

```
-2  -2  -2
 1   1   1
-1  -1  -1
```

Поэлементное произведение:

```
191*(-2)  126*(-2)   78*(-2)
 98*(1)    61*(1)     76*(1)
 94*(-1)   91*(-1)    92*(-1)
```

что даёт:

```
-382  -252  -156
  98   122   152
  188    91   184
```

`New_value = sum(-382, -252, -156, 98, 122, 152, 188, 91, 184) + bias = 45`

То есть новое значение центрального пикселя после применения этого фильтра равно **45**.

## Зачем нужны разные веса фильтра

Присваивая фильтру разные веса, можно выделять разные типы паттернов.

- **Вертикальные края**: значения в центре фильтра можно рассматривать как отсчёт от нуля (чёрного). Если соседние пиксели слева и справа похожи, они гасят друг друга. Но если слева резко тёмный участок, а справа резко светлый, — на выходе получается сильный отклик. Это именно то, что ожидается для вертикального края на изображении: фильтр улавливает контраст и подсвечивает, где на изображении встречаются вертикальные границы.
- **Горизонтальные края**: похожий по структуре фильтр, но развёрнутый — он выделяет горизонтальные границы.

Пример подобных фильтров (по презентации, соответствуют вертикальному/горизонтальному операторам типа Собеля):

```
Вертикальный:        Горизонтальный:
-1   0   1            -1  -2  -1
-2   0   2             0   0   0
-1   0   1             1   2   1
```

### Почему это важно для классификации

При распознавании бабочки человек не анализирует каждый пиксель по отдельности — он замечает форму крыльев, узор прожилок, характерные оранжево-чёрные участки. Мозг использует эти признаки, чтобы понять: это монарх. Для модели работает та же идея: фильтры помогают выделить паттерны, которые отличают монарха от парусника (swallowtail) или бабочку от жука.

**Ключевая идея CNN**: фильтры можно было бы проектировать вручную, но непонятно заранее, какие фильтры лучше всего подойдут для бабочек, цветов или жуков. Вместо этого модель сама учится подбирать и настраивать фильтры так, чтобы находить конкретные паттерны, отличающие каждый класс. Это и есть ключевая сила convolutional neural networks — они сами определяют, какие визуальные признаки важнее всего для конкретной задачи.

## Свёрточные слои в PyTorch: `nn.Conv2d`

Свёрточный слой создаётся так же, как и любой другой слой модели (например, ранее использовался `nn.Linear`). В PyTorch он определяется через `nn.Conv2d` — название означает, что это двумерная свёртка, как для двумерного изображения.

```python
# Basic convolutional layer
conv_layer = nn.Conv2d(
    in_channels=3,   # Number of input channels (e.g., RGB has 3)
    out_channels=16, # Number of output channels (number of filters)
    kernel_size=3,   # Size of the convolutional kernel (3x3)
    stride=1,        # Step size of the convolution
    padding=1        # Zero-padding around the edges
)
```

Разбор параметров:

- **`in_channels`** — число цветовых каналов входного изображения. Для фотографий природы это обычно 3 канала: red, green, blue.
- **`out_channels`** — сколько фильтров использует свёрточный слой. Каждый фильтр учится распознавать свой признак: например, один — края крыла, другой — глазчатые пятна, третий — текстуру пушистой поверхности. Обычно используется несколько фильтров, чтобы захватить все разные признаки на изображении.
- **`kernel_size`** — размер каждого фильтра; фильтр 3×3 — распространённый выбор, так как он рассматривает каждый пиксель вместе с его непосредственными соседями, что хорошо подходит для локальных паттернов (чешуйки крыла, текстура лепестка).
- **`stride`** — насколько далеко сдвигается фильтр на каждом шаге при сканировании изображения. Stride = 1 означает, что проверяется каждый пиксель. Увеличение stride заставляет фильтр пропускать пиксели — это быстрее, но есть риск упустить мелкие детали (например, сегменты усиков).
- **`padding`** — связан с размером ядра. Что происходит, если нужно центрировать фильтр на пикселе на краю изображения? Если приблизить угол изображения, граница окажется за пределами картинки, и при попытке центрировать фильтр на угловом пикселе у него не окажется соседних значений с одной или нескольких сторон. Значение padding = 1 просто добавляет такие недостающие значения по краям (по умолчанию они равны нулю). Это связано с размером ядра: например, при kernel_size = 5 потребуется padding = 2, чтобы можно было центрировать фильтр на угловом пикселе.

Так работают фильтры и то, как свёрточные слои используют их для нахождения полезных паттернов на изображениях — будь то тонкие прожилки крыла бабочки или спиральный узор лепестков цветка. В следующем видео рассматривается архитектура полной convolutional neural network: как свёрточные слои, pooling и полносвязные слои работают вместе, а затем эта архитектура реализуется в PyTorch.
