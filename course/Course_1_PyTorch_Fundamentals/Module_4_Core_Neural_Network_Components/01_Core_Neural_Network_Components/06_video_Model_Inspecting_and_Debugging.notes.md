## Отладка ошибки несовпадения размерности линейного слоя (продолжение ролика)

В транскрипции текст начинается с обсуждения PyTorch-ошибки, суть которой в том, что вход линейного слоя не совпал с тем, что слой ожидал.

В реальных проектах первое, что обычно проверяют, — это форму (shape) самого слоя.

- Если ошибка возникает на слое `FC1`, можно напечатать форму его весов, например так: `print(model.fc1.weight.shape)` — это даёт самый быстрый ответ.
- Но если непонятно, какой именно слой вызывает проблему, или нужно проверить сразу несколько слоёв, можно использовать `named_parameters()`, например:

```python
for name, param in model.named_parameters():
    if 'fc1.weight' in name:
        print(f"{name}: {param.shape}")
```

В рассматриваемом примере `FC1` ожидает **1024** входа, но модель на самом деле передаёт **2048**.

### Трассировка формы тензора через forward pass

Чтобы понять, откуда берётся такое несоответствие, предлагается вывести форму тензора прямо внутри `forward`-метода:

```python
def forward(self, x):
    print(f"Input: {x.shape}")
    x = self.features(x)
    print(f"After features: {x.shape}")
    x = x.flatten(1)
    print(f"Flattened: {x.shape}")
    x = self.classifier(x)
    return x
```

Так видно, какую форму выдаёт блок `features`, и корректно ли работает flatten.

Сочетая инспекцию модели (что ожидает `FC1`) с трассировкой формы (что он получает на самом деле), можно быстро определить, в каком месте что-то пошло не так. Именно так инспекция и отладка (inspection and debugging) работают вместе.
