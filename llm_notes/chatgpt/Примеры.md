Да — это именно новый **PyTorch for Deep Learning Professional Certificate от DeepLearning.AI / Laurence Moroney**. Сейчас программа состоит из трёх курсов по 4 модуля: Fundamentals → Techniques/Ecosystem → Advanced Architectures/Deployment. На странице DeepLearning.AI указаны 24 graded assignments; по структуре это по programming assignment на каждый из 12 модулей плюс остальные assessments. Темы доходят до TorchVision, Hugging Face, Optuna, Transformers, diffusion, MLflow, ONNX, pruning и quantization. ([DeepLearning.AI][1])
